# TASKORA

> A premium Telegram Mini App for discovering tasks, connecting verified social accounts, and earning through a personalized task marketplace.

## ✨ About TASKORA

TASKORA is being built as an account-linked task marketplace. Users see tasks that match the platforms they have connected and verified, creating a more personalized and relevant earning experience.

### Core experience

- 🔐 Secure account authentication and session handling
- 🔗 Connected and verified social platforms
- 🎯 Personalized tasks based on verified accounts
- 💰 Wallet and earning experience
- 📊 Task and account activity
- 🤖 TASKORA AI assistant experience
- 📱 Mobile-first Telegram Mini App interface
- ✨ Premium fintech/crypto-inspired visual design

## 🧱 Tech Stack

- React 19
- TypeScript
- TanStack Start / TanStack Router
- Vite
- Tailwind CSS
- Supabase
- React Query
- Radix UI
- Recharts
- Lucide React

## 🚀 Development

### Prerequisites

- Node.js
- npm
- A configured Supabase project for features that require the backend

### Install

```bash
git clone https://github.com/DannyYoung500/Taskoraplus.git
cd Taskoraplus
npm install
```

### Start the development server

```bash
npm run dev
```

The development server will start using Vite.

### Production build

```bash
npm run build
```

### Preview the production build

```bash
npm run preview
```

### Lint

```bash
npm run lint
```

## 🔒 Project Principles

TASKORA is designed around real user accounts and real application data.

- Do not replace the existing authentication system unnecessarily.
- Do not reset or delete production data during UI changes.
- Do not create duplicate wallet, user, or task systems.
- Do not replace real backend functionality with fake data.
- Preserve existing routes, integrations, and application logic when improving the interface.

## 🎨 Design Direction

TASKORA follows a premium dark fintech/crypto-inspired visual direction with a strong focus on mobile usability, clear information hierarchy, smooth transitions, and consistent branding across the app.

## 📌 Project Status

TASKORA is actively being developed. Features, integrations, and UI experiences are continuously being improved as the platform evolves.

## Strong next options (priority order)

1. **Withdrawal hold for new accounts** — 24–48h before first cash-out  
2. **Shared payout-address detection** — flag multi-account wallet reuse  
3. **Submission velocity limits** — e.g. max N proofs / hour  
4. **Campaign budgets** — stop task when budget spent  
5. **Advertiser deposits** — prepay USDT, spend on slots  
6. **Offerwall / rewarded video postbacks** — signed server callbacks only  
7. **Telegram channel membership verify** — bot must be admin in channel  
8. **Daily / weekly leaderboard prizes** — paid from platform pool  
9. **Support tickets** — in-app → owner queue  
10. **Broadcast announcements** — owner push to Mini App banner  
11. **Multi-tier referrals** — optional L2 at low %  
12. **Audit export** — CSV of admin actions for compliance
